## Scope reviewed

This change adds an explicit operating-state objective layer on top of the already reviewed geometry generator, suspension-pose provider, and `MOD-STEER-0001` analyzer. It does not add steering equations, suspension kinematics, tire-force physics, load physics, compliance, or physical-data corrections.

The reviewed chain is:

```text
candidate geometry
 -> provider-supplied suspension poses
 -> complete MOD-STEER-0001 rack sweeps
 -> explicit state target roles/curves/weights
 -> visible per-state objective contributions
 -> deterministic aggregate ranking using the existing search method
```

## Architecture disposition

Accepted for review:

- Each suspension state is explicitly `objective` or `report_only`.
- The first target-set contract requires unlisted states to be `report_only`; nominal targets are never silently inherited by another pose.
- Report-only states remain part of the hard operating envelope and must complete the analyzer sweep.
- Every objective state retains left/right target curves, sample weights, normalization, objective weight, sign convention, source, authority, and provenance.
- Candidate infeasibility at any supplied pose produces no aggregate objective.
- The aggregate score is only the documented sum of visible normalized state terms.
- `run_operating_state_inverse_design` reuses the same `bounded_coordinate_pattern_search_v0.1.0` core as the nominal optimizer; no new numerical search method or second mechanism model is introduced.
- The explicit table loader permits later manual, geometric, external vehicle-dynamics, or tire-informed targets without changing the steering kernel.

## Literature review

The implementation documentation and literature concordance ground the state-indexed architecture in:

- Guiggiani, *The Science of Vehicle Dynamics* (2022), Sections 3.4.2-3.4.3: static/dynamic toe influence tire slips, lateral-force values/directions, and best steering geometry depends on operating conditions rather than one universal Ackermann relation.
- Guiggiani, Section 3.14.6 and Eq. (3.210): with roll steer, wheel steer is a function of steering input and suspension roll angle, supporting state-dependent steering response.
- Gillespie, *Fundamentals of Vehicle Dynamics*, Chapter 8 `Steering Geometry Error`, `Toe Change`, and `Roll Steer`: suspension jounce/rebound/roll can create steering action through linkage geometry.
- Romano: staged steering-assembly, suspension, and full-vehicle integration remains the architectural precedent.
- Hooke-Jeeves and Lewis/Torczon/Trosset: the existing deterministic direct-search baseline remains the numerical method; PR #25 changes the objective adapter, not the search algorithm.

The state-weighted aggregate itself is explicitly a project optimization method, not a textbook vehicle-dynamics law. Its weights and normalizations remain visible provider inputs.
