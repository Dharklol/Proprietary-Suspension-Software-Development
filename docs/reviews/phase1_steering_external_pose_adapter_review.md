## Scope reviewed

This change adds a source-neutral file-exchange boundary between an external suspension model and the already reviewed `SuspensionPoseSet` interface. It adds no suspension-kinematics equations and no steering equations.

The reviewed chain is:

```text
SolidWorks / OptimumK / lookup table / future native solver
        -> source-specific reviewed conversion
        -> canonical CSV + TOML external pose exchange
        -> SuspensionPoseSet
        -> existing pose application
        -> MOD-STEER-0001 tie-rod closure and rack sweeps
```

The current PR verifies the middle portion of that chain with synthetic fixture data. It does not claim that a WUFR source-specific exporter has been recovered or validated.

## Architecture disposition

Accepted for review:

- The exchange table contains full left/right rigid transforms for named suspension states rather than reduced toe/camber outputs.
- Version 0.1 accepts only canonical body-frame translations in metres and full active `3x3` rotation matrices using the declared `active_nominal_upright_to_state_body_frame` convention.
- The manifest requires source path, source revision, authority, frame identity/definition, state-coordinate identities/units, and the steering-DOF declaration.
- `tie_rod_steering_response_included=false` is mandatory; a source that already contains tie-rod-induced steering is rejected before mechanism evaluation.
- Vendor-specific axis, handedness, Euler-order, sign, or unit conversion is deliberately outside the steering adapter. A source-specific exporter must perform and document that conversion upstream.
- Valid imported poses still pass through the existing `SuspensionPoseSet`, `RigidTransform`, pose application, and `MOD-STEER-0001` checks.
- A valid pose that makes tie-rod closure impossible remains a steering-state infeasibility rather than becoming an import-format error.

## Literature/physics boundary

No new physical equation requires authorization in this PR. The external adapter exists to preserve the literature-grounded separation already established by the pose layer:

- Gillespie supports suspension-state-dependent steering geometry error, toe change, and roll steer;
- Guiggiani supports treating roll steer/toe as state-dependent suspension/setup behavior;
- Romano supports staged steering-assembly to suspension/full-vehicle integration.

The adapter only transports the state geometry required by that existing model architecture.

## Authority boundary

The review does **not** promote:

- the synthetic external fixture to WUFR suspension motion;
- descriptive SolidWorks/OptimumK references to a numerical pose data source;
- measured toe/camber validation data to an unresolved upright pose;
- any unreviewed source-specific coordinate conversion;
- any imported table to WUFR design-ranking authority merely because it parses successfully;
- any result to packaging, manufacturing, robustness, tire-optimal, effort, production, or as-built authority.

A future WUFR pose source must independently freeze its source revision, frame conversion, unresolved-steering treatment, nominal identity, and reconstruction checks before it is used for WUFR state-dependent design ranking.

`P1-STR-006E` remains explicitly deferred until physical Level F evidence exists.

## Review conclusion

The generic external exchange adapter is cohesive with the existing steering stack and removes the need to write source-specific assumptions into the optimizer. After PR #26 review and merge, a SolidWorks, OptimumK, explicit model table, or future native suspension solver can target one canonical interface. Until an actual reviewed WUFR pose export is supplied, synthetic and external-fixture state studies remain software-development evidence only.
