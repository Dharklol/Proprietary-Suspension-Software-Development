# Phase 3 provider-neutral linkage statics implementation review

## Scope

PR #69 implements `MOD-SUSP-0006` under merged `AUTH-SUSP-0010`.

The runtime problem remains exactly the authorized one:

`one rigid body + exactly six ideal pin-ended two-force links + one prescribed external wrench -> six signed axial link forces`.

No WUFR tire/load-case generator or current-car corner adapter is included.

## Implementation

`src/pssd_suspension/linkage_statics.py` provides:

- explicit link IDs, common frame, body application points, and remote endpoints;
- a prescribed external force/couple about an explicit reference point;
- positive-tension link-axis construction;
- exact 6x6 force/moment equilibrium assembly;
- moment-row scaling using `L_ref=max ||r_body-r_O||`;
- deterministic partial-pivot direct solves;
- `cond_inf` evaluation from deterministic inverse-column solves;
- singular and ill-conditioned failure gates;
- physical-unit force/moment reconstruction after the solve;
- equal-and-opposite remote-end link actions;
- structured failure/provenance output.

The implementation has no NumPy/SciPy dependency and does not call a least-squares, pseudoinverse, minimum-norm, regularized, or stiffness-weighted solver.

## Verification

`BENCH-SUSP-0018` recovers the frozen analytical target

`N=[100,200,300,40,50,60] N`

from

`F_ext=[-150,-260,-340] N`

and

`M_ext=[-40,-50,-60] N*m`.

The nominal scaled matrix has `cond_inf=4` and exact physical force/moment residuals in the analytical fixture.

`BENCH-SUSP-0019` changes the moment reference to `[0.31,-0.17,0.23] m` with exact wrench translation and also rigidly translates the complete geometry. Both representations preserve the same physical axial-force solution.

`BENCH-SUSP-0020` checks fail-closed behavior for degenerate endpoints, five/seven-link topology, singular six-link geometry, near-singular geometry above the `1e10` condition limit, and nonfinite input. No failed topology returns an approximate force vector.

The machine-readable result is frozen in `benchmarks/suspension/suspension_linkage_statics_result_v0.1.0.toml` and is regenerated by `scripts/run_suspension_linkage_statics_benchmarks.py`.

## Physical fidelity boundary

This implementation verifies the mechanics and software contract of the ideal axial-link baseline. It does not validate `ASM-SUSP-0004` as a final structural representation of a welded Formula SAE suspension.

Borg (2009) is intentionally used on both sides of that boundary: the truss formulation gives the six-member force/moment architecture, while the thesis' later beam comparison and steering-articulation results demonstrate why bending and actual geometry/load paths must remain a higher-fidelity layer.

## WUFR hold

No WUFR member forces are published by PR #69.

The reviewed WUFR actuation source places the front push/pull pickup on the upper A-arm and the rear pickup on the lower A-arm. A subsequent source/topology audit must decide the correct rigid-body/massless-joint graph before adapting `MOD-SUSP-0006` to WUFR. The generic kernel is not permission to move either pickup to the upright for convenience.

## Next linkage-statics gate

The next linkage work should be a WUFR load-path/topology authorization, not another generic linear solver. It should freeze the actual body/joint/link graph, steering/tie-rod and rear toe-link roles, arm-mounted actuation paths, rocker/coilover/ARB interfaces, brake torque reaction path, and the authority for any prescribed external wrench before a current-car member-force result is produced.
