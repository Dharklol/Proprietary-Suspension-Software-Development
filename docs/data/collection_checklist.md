# Measurement Collection Checklist

1. Copy the versioned templates into a new session directory.
2. Fill the setup manifest and retain photographs/drawings.
3. Use existing `SNS-*`, `QTY-*`, and performed `CAL-*` IDs.
4. Declare actual channels, rates, clocks, polarity, and zeros.
5. Validate the empty/header package before acquisition.
6. Preserve raw logger exports and hashes.
7. Validate the completed package before analysis.
8. Record processing code commit and evidence role.
